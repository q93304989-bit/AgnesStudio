# Agnes 图像/视频生成小工具

一个集成 **图片生成**（文生图 / 图生图）与 **视频生成**（文生视频 / 图片参考视频）的桌面应用。

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 🎨 **图片生成** | 输入文字描述生成图片；添加参考图则自动切换为图生图（支持多张参考图） |
| 🎬 **视频生成** | 输入文字描述生成视频；添加参考图则自动切换为图片参考视频（文字+图片同时输入） |
| 🕘 **历史记录** | 自动保存每次生成的提示词、输入参数、参考图与结果，支持筛选/搜索/回看/复用参数 |
| ⚙ **设置页** | 密钥管理 + 测试连接、图床密钥、生成默认值、网络模式、主题、存储目录（默认 F:\AgnesGeneratorData） |

### 其他特性
- ✅ 参考图支持 **URL 直填** 或 **本地文件**（自动转 base64）
- ✅ 图片/视频参考图列表（添加/删除/清空/缩略图预览，最多 5 张）
- ✅ 历史记录自动落盘（`history.json` + 本地图片缓存），重启不丢
- ✅ 历史条目一键 **载入参数**（回填提示词、尺寸/模型/时长/画幅、参考图）重新生成
- ✅ 视频异步生成，实时显示任务状态与进度（1.5s 轮询）
- ✅ 生成结果实时预览（图片内嵌预览；视频调用系统播放器）
- ✅ 一键复制 URL / 保存到本地（图片 PNG/JPEG，视频 MP4）/ 浏览器打开
- ✅ 视频参数可选：时长（4/5/8/10/12秒）、画幅（16:9/9:16/1:1/4:3/3:4/21:9）
- ✅ 后台线程生成，界面不卡顿
- ✅ API 异常友好提示

## 📦 项目结构

```
图像/视频生成小工具/
├── main.py              # 主程序（GUI 界面：图片 / 视频 / 历史记录三个标签页）
├── agens_core.py        # Agnes 图片生成核心模块
├── video_core.py        # Agnes 视频生成核心模块（异步任务）
├── history_store.py     # 历史记录存储（JSON 索引 + 本地图片缓存）
├── history_ui.py        # 历史记录面板 UI（筛选 / 搜索 / 卡片列表 / 条目操作）
├── app_config.py        # settings.json 读写与默认项（主题/网络/默认值/存储目录）
├── http_session.py      # 统一 HTTP 会话（自适应网络模式）
├── requirements.txt     # Python 依赖
├── .env                 # API 密钥配置
└── app_icon.png         # 应用图标
```

### 历史记录数据存放位置

历史记录**不写在程序目录**（打包后的 exe 常在只读目录），默认放在 **F 盘数据目录**：

| 系统 | 路径 |
|------|------|
| Windows（默认） | `F:\AgnesGeneratorData\` |
| 旧版 / 非 Windows 兜底 | `%APPDATA%\AgnesGenerator\` 或 `~/.agnes_generator/` |

```
F:\AgnesGeneratorData/
├── history.json    记录索引（类型 / 状态 / 时间 / 提示词 / 参数 / 参考图 / 结果 URL）
├── media/          图片本地缓存（生成时自动保存，可离线回看）
└── thumbs/         列表缩略图
```

- 设置页「文件存储地址与历史记录」可修改为任意文件夹（默认 F:\AgnesGeneratorData）
- 可用环境变量 `AGNES_HISTORY_DIR` 覆盖设置（优先级最高）
- 首次启动会自动把旧版 `%APPDATA%` 下的历史迁移到 F 盘目录
- 历史面板的 📂 按钮可直接打开该目录

## 🚀 快速开始（源码运行）

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置 API 密钥

编辑 `.env` 文件，确保包含：

```env
AGNES_API_KEY=sk-你的密钥
AGNES_BASE_URL=https://apihub.agnes-ai.com/v1
```

### 3. 运行程序

```bash
python main.py
```

## 🛠️ 使用说明

### 🎨 图片生成

1. 切换到「图片生成」标签页
2. 输入提示词（可点击示例按钮快速填充）
3. （可选）点击「+ 添加URL」或「+ 浏览文件」添加参考图
   - 不添加参考图 → 文生图
   - 添加参考图 → 图生图（支持多张）
4. 选择图片尺寸和模型
5. 点击「🚀 开始生成图片」

### 🎬 视频生成

1. 切换到「视频生成」标签页
2. 输入提示词（描述视频内容与动态效果）
3. （可选）添加参考图（最多 5 张）
   - 不添加参考图 → 文生视频
   - 添加参考图 → 图片参考视频（文字+图片同时输入）
4. 选择时长、画幅、模型
5. 点击「🎬 开始生成视频」
6. 视频为异步生成，**通常 1-3 分钟**，请耐心等待状态栏进度
7. 完成后可 **▶ 播放**（系统默认播放器）、**保存**（MP4）或 **复制 URL**

> **注意**：
> - 视频生成需要 Agnes 账户有余额（当前平台限时免费，政策变动以平台公告为准）
> - 视频 API 限流：每 60 秒最多 2 次请求
> - 参考图若为本地文件，图片生成会自动转 base64；视频的参考图如遇服务端不支持 base64，请改用公网 URL

### 🕘 历史记录

1. 切换到「🕘 历史记录」标签页
2. 每次生成（成功或失败）都会自动记录一条：提示词、输入参数、参考图、结果 URL
3. 顶部可按 **全部 / 图片 / 视频** 筛选，或用搜索框按提示词 / 参数搜索
4. 点击任意条目：右侧展示大图（图片）或视频信息，下方列出完整提示词与参数
5. 底部按钮：
   - **载入参数** — 回填提示词与全部参数到对应生成页，方便微调后重跑
   - **删除** — 删除该条记录（同时删除本地缓存图片）
   - **清空全部** — 清空所有历史
6. 右侧通用按钮同样作用于当前选中的历史记录：
   - **复制 URL / 浏览器打开** — 打开该条结果的原始链接
   - **保存** — 图片优先从本地缓存复制，视频或缓存缺失时重新下载
   - **▶ 播放** — 仅视频记录可用，调用系统播放器在线播放

> **说明**：
> - 图片生成完成后会自动把图片缓存到本地，历史列表直接显示缩略图，离线也能回看
> - 视频只保存元数据与 URL（避免占用大量磁盘），需要时再「保存」下载
> - 最多保留 500 条记录，超出后自动清理最旧的

## 🛠️ 设置页

左侧导航点击「⚙ 设置」即可管理全部设置项：

| 设置 | 说明 |
|------|------|
| 🔑 **密钥管理** | 编辑 `AGNES_API_KEY` / `AGNES_BASE_URL` 并保存到程序目录 `.env`；「测试连接」会请求 `/models` 验证密钥与网络（显示耗时与 HTTP 状态） |
| 🖼 **图床密钥** | 视频参考图自动上传所需：GitHub Token + 仓库（免费推荐）或 S.EE Token（付费） |
| 🎛 **生成默认值** | 图片尺寸/模型、视频时长/画幅/模型，保存后立即应用到生成页下拉框 |
| 🌐 **网络模式** | 自动（直连优先失败换代理）/ 仅直连 / 仅系统代理，应对本机代理不稳定的两种场景 |
| 🎨 **主题** | 跟随系统 / 浅色 / 深色（CustomTkinter 外观模式） |
| 📂 **文件存储地址** | 历史记录、图片/视频缓存、缩略图与保存对话框默认目录（默认 `F:\AgnesGeneratorData`） |

偏好保存到 `%APPDATA%\AgnesGenerator\settings.json`，密钥仍保存在程序目录 `.env`（两者分离，便于整机迁移）。

## ⚙️ 支持的参数

### 图片

| 参数 | 选项 |
|------|------|
| 尺寸 | 1024x768 / 512x512 / 768x1024 / 1024x1024 / 1280x720 / 720x1280 / 1920x1080 |
| 模型 | agnes-image-2.1-flash |

### 视频

| 参数 | 选项 |
|------|------|
| 时长 | 4 / 5 / 8 / 10 / 12 秒 |
| 画幅 | 16:9 (1280x720) / 9:16 (720x1280) / 1:1 (720x720) / 4:3 / 3:4 / 21:9 |
| 尺寸 | 固定 720P |
| 模型 | agnes-video-2.5 / agnes-video-v2.0 |

## 📦 打包为 EXE（Windows）

```bash
pyinstaller --noconfirm --onefile --windowed ^
  --name "Agnes生成小工具" ^
  --add-data ".env;." ^
  --add-data "app_icon.png;." ^
  --icon app_icon.png ^
  main.py
```

或使用 spec 文件：

```bash
pyinstaller AgnesImageGenerator.spec
```

> **注意**：打包后需要将 `.env` 文件放到 exe 同目录下，程序会自动读取。
